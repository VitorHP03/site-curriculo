Parte 1

Meu projeto funcional

- Eu criei esse sistema pois vi a necessidade de algo que não tinha na empresa, antes não tínhamos um controle dos materiais que iriam para zincagem/corte, anotávamos em papéis a caneta.

- Támbem não tinha uma forma de passsar os materiais necessarios para a compra para o nosso estoque, era tudo via whatssap para o dono da empresa.

- Com essa necessidade de controlar melhor o estoque e a expedição, iniciei o projeto do sistema, usando banco que dados que atualiza as informções em tempo real para todos que estão usando o sistema, está sendo usando desde terça-feira (07/07/26) pelos vendedores externos, expedição/estoque e até mesmo o dono da empresa, para melhor acompanhamento de tudo que está acontecendo.
